# ספריית וידאו

כל הסרטונים שנוצרים, לפי פרויקט וגרסה — במקום אחד. http://localhost:5757

## הפעלה

לחיצה כפולה על `start.cmd` (או `npm start`).

## הוספת וידאו

```
node register.mjs <video.mp4> [--project P] [--version N] [--variant V] [--note "..."]
node register.mjs --scan <folder> --project P
```

או דרך ה־API (כשהשרת רץ):

```
POST /api/videos   { "path": "...", "project": "...", "note": "..." }
POST /api/scan     { "dir": "...",  "project": "..." }
```

או מכפתור ה־＋ באפליקציה.

- גרסה ווריאנט (dark / light / dubbed / feed …) מזוהים אוטומטית מהנתיב: תיקיית `v2/` או `-v2` בשם הקובץ. בלי מספר גרסה — רינדור חדש של וריאנט קיים מקבל את הגרסה הבאה.
- כל קובץ מועתק ל־`data/library`, כך שגרסאות ישנות נשמרות גם אם הקובץ המקורי נדרס.
- הסרה מהספרייה לא מוחקת את הקובץ המקורי.
- `node register.mjs --rethumb` — בניית תמונות ממוזערות מחדש.

### קליטה אוטומטית

כל תיקייה שכבר נרשם ממנה סרטון נמצאת במעקב (כולל תיקיות רינדור בתוכה: `out/`, `v3/`, `renders/` …). רינדור חדש שמסיים להיכתב נרשם לבד לאותו פרויקט, ואחרי דקה וחצי של שקט מתפרסם לבד. קבצים עם `preview`, `draft`, `tmp`, `test` בשם מדולגים.

### עותק קל

לכל סרטון מעל 12MB נוצר עותק 720p (`data/light`) — משמש ל"שליחה כסרטון" ולתצוגה מקדימה, כדי ששליחה מהטלפון תהיה מהירה.

## לקוחות — צפייה ואישור

לכל פרויקט יש לינק פרטי: `https://lawebs.co.il/videos/p/<token>/` (כפתור **לינק ללקוח** בראש הפרויקט). הלקוח רואה רק את הפרויקט שלו, מאשר גרסה או מבקש תיקון — אפשר לנעוץ הערה לרגע בסרטון. גם צפייה נרשמת.

הכל חוזר לאפליקציה תוך פחות מדקה: סימון על כל גרסה (אושר / תיקונים / נצפה), שרשור הערות עם קפיצה לזמן, והתראה.

- ה־API רץ בשרת תחת pm2 (`video-library-api`, פורט 3192), קוד ב־`api/server.mjs`. הנתונים ב־`/var/lib/video-library/events.jsonl` ולא מוחלפים בפריסה.
- האפליקציה המקומית מושכת את הפידבק עם מפתח צוות (`data/team.key`, נשלף אוטומטית בפריסה הראשונה).
- תצוגה מקומית של הייצור כולל ה־API: `node scripts/build-static.mjs && node scripts/preview-prod.mjs` → http://localhost:5760/videos/

## מסך הבית — מה דורש טיפול

- **מספרים:** תיקונים פתוחים · מוכנים לשליחה · נשלחו ולא נצפו · אושרו. לחיצה על מספר מסננת את הפרויקטים.
- **דורש טיפול:** בקשות תיקון של לקוחות (קפיצה לרגע בסרטון, וכפתור "טופל"), גרסאות חדשות שעוד לא נשלחו (שליחה בוואטסאפ / העתקה / "כבר נשלח"), ולינקים שנשלחו לפני יותר מיומיים ולא נצפו (תזכורת).
- **פעילות אחרונה:** סרטונים חדשים, צפיות, תגובות, אישורים ולינקים שנשלחו.
- **שליחה נרשמת:** כל העתקה או פתיחה בוואטסאפ של לינק ללקוח נשמרת (`data/local.json`, יחד עם מה שסומן "טופל").
- **גרירה:** גרירת קובץ וידאו לחלון מוסיפה אותו לפרויקט הפתוח.

## קיצורי מקלדת

`Ctrl K` חיפוש ופעולות (פרויקט, גרסה, לינק ללקוח, פרסום) · `/` חיפוש · `←` `→` גרסה הבאה / קודמת · `C` השוואה · `Esc` כל הפרויקטים · `?` עזרה

## ייצור — https://lawebs.co.il/videos/

```
powershell -File deploy.ps1                  # GitHub ואז ייצור
powershell -File deploy.ps1 -Target GitHub   # רק GitHub
powershell -File deploy.ps1 -Target Prod     # רק ייצור (אחרי push)
```

או בכפתור הפרסום בתחתית סרגל הצד באפליקציה — הוא גם מראה אם יש שינויים שעוד לא עלו.

הקוד נדחף ל־`main` ב־[GitHub](https://github.com/lironatar1994-coder/Video-Claude-Manager), והייצור עולה רק כש־`main` ב־GitHub תואם בדיוק לגרסה המקומית (`/videos/revision.txt`). הסרטונים עצמם לא נכנסים ל־git.

בונה עותק סטטי לקריאה בלבד (`scripts/build-static.mjs`), מעלה לשרת `vee-app.co.il` רק סרטונים חדשים, ומחליף גרסה דרך `scripts/deploy-linux.sh` (snippet של nginx תחת `lawebs.co.il`, גיבוי ו־rollback אוטומטי). על השרת: `/opt/video-library`. הדף מסומן `noindex`.

Claude Code מקבל הנחיה ב־`~/.claude/CLAUDE.md` לרשום כל וידאו שהוא יוצר.
